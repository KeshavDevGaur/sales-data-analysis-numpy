# Sales Data Analysis using NumPy

## Overview
This project is a beginner-friendly data analysis project built using NumPy. It analyzes sales data across different months and products to generate useful business insights.

## Features
- Total yearly sales analysis
- Product-wise sales analysis
- Month-wise sales analysis
- Average sales calculation
- Highest and lowest sales identification
- Best performing product detection
- Lowest performing product detection
- Best sales month detection
- Monthly average sales analysis
- High sales filtering using NumPy

## Technologies Used
- Python
- NumPy

## Learning Outcomes
Through this project, I practiced:
- NumPy arrays
- 2D array operations
- Aggregation functions
- Axis-based calculations
- Filtering data with conditions
- Finding insights from structured data
